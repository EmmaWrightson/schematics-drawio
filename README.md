# schematics-drawio

A small repository containing Draw.io diagrams used in Triton-AI projects.

### Install the Draw.io (vscode-drawio) extension
- Install from the VS Code Marketplace: https://marketplace.visualstudio.com/items?itemName=hediet.vscode-drawio
- Install via the VS Code CLI:

```bash
code --install-extension hediet.vscode-drawio
```

After installing, you can open `.drawio` files directly in VS Code (they will open in the Draw.io editor).

### Clone this repository
Use the SSH clone (recommended if you have SSH keys configured):

```bash
git clone git@github.com:Triton-AI/schematics-drawio.git
```

Then open the repository in VS Code:

```bash
code .
```
